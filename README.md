# 🚢 Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Titanic dataset using Python.

The main objective is to analyze passenger information and identify patterns related to survival.

## 🎯 Objectives
- Understand the Titanic dataset.
- Identify and handle missing values.
- Perform data cleaning.
- Analyze passenger survival patterns.
- Visualize data using charts and graphs.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Analysis Performed
1. Data Loading and Inspection
2. Data Cleaning
3. Missing Value Analysis
4. Gender-wise Survival Analysis
5. Passenger Class Analysis
6. Age Distribution Analysis
7. Data Visualization

## 📈 Key Insights
The analysis explores:
- Relationship between gender and survival.
- Relationship between passenger class and survival.
- Age distribution of passengers.
- Factors associated with passenger survival.

## 🚀 How to Run
1. Download the repository.
2. Open `Titanic_EDA.ipynb` using Google Colab or Jupyter Notebook.
3. Upload the Titanic dataset (`train.csv`).
4. Run the notebook cells sequentially.
